# Processed Data

## English

This folder stores processed datasets that are ready for research use.

The most important subfolder is:

- [`algorithm_ready`](algorithm_ready)

It contains:

- graph-ready nodes
- segments
- directed edges
- connected-component metadata
- graph validation reports
- QGIS-friendly GeoJSON and GPKG outputs

If you want to rerun the routing pipeline, point `--data` to this folder.

## 中文

這個資料夾存放的是已整理完成、可直接用於研究的資料。

目前最重要的子資料夾是：

- [`algorithm_ready`](algorithm_ready)

它包含：

- graph-ready nodes

- 可直接匯入 QGIS 的 GeoJSON 與 GPKG

Path Routing Literature Summary
===============================

English Summary
---------------

Goal
1. Identify a rigorous baseline for shortest-path and routing tasks.
2. Explain why single-bit flip is weak for routing-like QUBO problems.
3. Identify stronger neighborhood ideas from the literature.

Main conclusions
1. Dijkstra should be treated as the exact baseline for the current weighted shortest-path setting.
2. One-flip local search is structurally vulnerable to local minima in QUBO landscapes.
3. Routing heuristics in the literature usually rely on structured route moves rather than naive bit-by-bit updates.
4. Multi-neighborhood methods such as VNS are widely supported in routing research.

Key references and their role
- Dijkstra (1959): exact baseline for shortest path with nonnegative edge weights
- Verma and Lewis (2021): one-flip local optima are meaningful traps in QUBO landscapes
- Osman (1991): simulated annealing paired with 3-opt for VRP, showing route-level moves matter
- VNS literature: multiple neighborhoods are often stronger than a single local move in routing-like problems

Implication for this project
- The real weakness is not checkerboard speed or odd/even update logic.
- The real weakness is that a one-edge flip neighborhood is too local for a path structure.
- A valid route usually requires coordinated changes across multiple edges.
- That is why fragmentary edge sets appear more easily than a complete path.

Operational recommendation
- Keep Dijkstra as the correctness oracle.
- Compare every SQA result against the same edge-cost definition.
- Replace or augment single-bit flip with structured path moves such as:
  - warm-start from a path
  - segment insertion / deletion
  - 2-opt style reconnect
  - cycle/path repair
  - variable-neighborhood search

Best practical recommendation
1. Keep Dijkstra as baseline and warm-start source.
2. Stop relying only on random bit initialization for routing.
3. Add repair-aware local search with path-segment moves.

中文摘要
--------

目標
1. 找出 shortest-path / routing 題目的嚴謹 baseline。
2. 說明為什麼 single-bit flip 對 routing 類 QUBO 題目很弱。
3. 找出文獻中更合理的 neighborhood 設計。

主要結論
1. 在目前的加權最短路設定下，Dijkstra 應該被視為精確 baseline。
2. one-flip local search 在 QUBO landscape 中本來就容易卡在局部最小值。
3. routing 文獻通常使用有結構的 route moves，而不是 naive 的逐 bit 更新。
4. 像 VNS 這種多鄰域方法，在 routing 研究裡有很強的支持。

關鍵文獻與用途
- Dijkstra (1959): 非負權重最短路的精確 baseline
- Verma and Lewis (2021): 說明 one-flip local optima 是 QUBO 中真實存在的陷阱
- Osman (1991): SA 與 3-opt 結合解 VRP，顯示 route-level move 很重要
- VNS 系列文獻：說明多鄰域通常比單一鄰域更適合 routing 類問題

對本專案的意義
- 真正的弱點不是 checkerboard 更新快不快。
- 真正的弱點是 one-edge flip neighborhood 對 path structure 太局部。
- 合法路徑通常需要多條邊同時協調。
- 這就是為什麼零碎 edge set 比完整 path 更容易出現。

實務建議
- 把 Dijkstra 當成 correctness oracle。
- 每一個 SQA 結果都要用同一套 edge cost 與 Dijkstra 比較。
- 用更有結構的 path moves 取代或補強 single-bit flip，例如：
  - path warm start
  - segment insertion / deletion
  - 2-opt style reconnect
  - cycle/path repair
  - variable-neighborhood search

最實際的下一步
1. 保留 Dijkstra 當 baseline 與 warm-start 來源。
2. 不要再只依賴 random bit initialization 來做 routing。
3. 加入帶 repair 能力的 path-segment local search。

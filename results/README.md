# Results

## English

This folder stores curated benchmark outputs rather than every scratch result produced during development.

It is organized into two main lines:

- [`single_route`](single_route): the earlier single-route phase, mainly used to diagnose pure SQA, warm start, and block-move behavior
- [`alternative_route`](alternative_route): the current main line, aligned with kSPwLO-style alternative routing

Each result package tries to keep:

- manifests
- summary CSV / JSON files
- overview figures
- representative run outputs when needed
